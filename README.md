# portfolio# Personal Portfolio Website

A responsive personal portfolio website showcasing my skills, education, projects, coding achievements, and contact information.

## About

This portfolio was built to present my journey as a Computer Science student, developer, and problem solver. It highlights my technical skills, academic background, projects, and competitive programming achievements.

## Features

- Responsive modern design
- Light Mode and Dark Mode toggle
- Smooth scrolling navigation
- Skills section
- Education timeline
- Project showcase
- Competitive programming profiles
- Resume download option
- Contact form powered by EmailJS
- Mobile-friendly layout

## Tech Stack

- HTML5
- CSS3
- JavaScript
- EmailJS
