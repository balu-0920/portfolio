# Portfolio Website

A modern and responsive personal portfolio website built to showcase skills, education, projects, achievements, and professional journey in a clean and interactive way.

## Features

- Modern and responsive UI
- Light and Dark mode toggle
- Smooth scrolling navigation
- Professional hero section
- About Me section
- Skills showcase
- Education timeline
- Project portfolio section
- Coding achievements section
- Resume download option
- Contact form integration using EmailJS
- Mobile-friendly design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- EmailJS

## Sections

### Home
Introduction, profile overview, and quick access to resume and contact information.

### About
Overview of background, interests, and career goals.

### Skills
- Programming Languages
- Frontend Development
- Databases
- Tools & Technologies
- Computer Science Fundamentals

### Education
Academic journey and achievements.

### Projects
Collection of software development and problem-solving projects including:
- Crowd Management System
- AI-based Placement Preparation Platform
- Online Trading Simulator
- Attendance Tracking System

### Coding Journey
Highlights of competitive programming activities and achievements across multiple coding platforms.

### Contact
Integrated contact form for direct communication.

## Getting Started

1. Clone the repository

```bash
git clone <repository-url>
```

2. Open the project folder

```bash
cd portfolio
```

3. Open `index.html` in your browser

or

4. Deploy using platforms such as:
   - Vercel
   - Netlify
   - GitHub Pages
